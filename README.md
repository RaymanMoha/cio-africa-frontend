
## Setup Instructions

### Prerequisites
- Node.js (v14 or higher)
- npm (v6 or higher)
- Git

### Installation

Clone the repository:
```bash
git clone https://github.com/RaymanMohs/cio-africa-frontend
```
Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run start
```

5. Run tests:
```bash
npm run test
```

6. Run linting:
```bash
npm run lint
```
