
## Setup Instructions

### Prerequisites
- Node.js (v14 or higher)
- npm (v6 or higher)
- Git

### Installation

Clone the repository:
```bash
git clone https://github.com/RaymanMoha/cio-africa-frontend
```
Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run start
```
